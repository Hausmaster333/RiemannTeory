# Теорема Римана

Откройте `Riemann.exe` на Windows. Python устанавливать не нужно. Нажмите на формулу или «Выбрать ряд», чтобы переключить пример. Цель `L` и точность `ε` при переключении сохраняются.

Доступны четыре условно сходящихся ряда:

- Параметрический: `(-1)^(n+1) (A + B sin n) / n^p`, где `A > |B|` и `0 < p ≤ 1`.
- Гармонический: `(-1)^(n+1) C / n`.
- Ряд Лейбница: `(-1)^(n+1) C / (2n-1)`.
- Синусный: `C sin n / n`.

Для последних трёх рядов `C > 0`. Кнопки управляют анимацией; ползунок позволяет перейти к любому вычисленному шагу. Серый график показывает исходный порядок, тёмный — перестановку к `L`.

Число шагов означает **устойчивое** приближение: с этого шага все последующие частичные суммы остаются в пределах `ε` от `L`. Программа проверяет это достаточным условием через убывающую верхнюю границу членов выбранного ряда. Предварительный расчёт ограничен 200 000 шагами; если этого мало, выводится грубая оценка порядка величины со знаком `≈`.

## Почему эти ряды подходят

Для параметрического ряда сходимость следует из признака Дирихле; сумма модулей расходится, поскольку `|aₙ| ≥ (A−|B|)/n^p`. Гармонический ряд и ряд Лейбница сходятся по признаку чередующихся рядов, а ряды их модулей расходятся. Синусный ряд сходится по признаку Дирихле; сумма `|sin n|/n` расходится, так как `|sin n| ≥ sin² n`, а `Σ sin² n / n` расходится. Поэтому к каждому из четырёх рядов применима теорема Римана.
